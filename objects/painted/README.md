# The painted drawer

Painted cutouts: PNG files with see-through backgrounds, named after the drawer object they replace
(`candle.png`, `seashell.png`, `pearl.png`...). This set is painted for Rocha's example altar.

Use one on your altar the same way you use your own pictures:

```json
{ "type": "painted/candle.png" }
```

If a painted file is missing, the altar uses the flat drawing of the same name instead, so it always builds.
You can paint your own set too. Put your PNGs in an `objects/painted` folder next to your altar.config.json.
